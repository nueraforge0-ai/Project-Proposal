### 3.8 System Testing and Evaluation

Testing will show how well the prototype meets the requirements and the five evaluation criteria in Chapter One. Table 3.4 shows the tests.

**Table 3.4: Testing and evaluation activities**

| **Criterion or test** | **What will be checked** | **Method** |
|----|----|----|
| Functionality | Whether registration, reporting, search, claims, release, notifications and account management work as specified | Unit, integration and functional test cases |
| Security | Whether role restrictions work (for example, a student cannot open another user's claim or a stored photograph), whether harmful input and unsafe uploads are rejected, and whether login protections work | Role-based access tests; input and upload tests |
| Reliability | Whether the system runs without failure or data loss during a test period and handles errors and poor connectivity | Repeated test runs; fault log; low-connectivity tests |
| AI matching | Whether the correct found item appears among the top three suggestions for a simulated lost report | Test set of simulated lost and found pairs; count of correct matches in the top three suggestions |
| Usability | How easily users complete tasks such as reporting a loss or claiming an item | Task-based user testing; System Usability Scale (Brooke, 1996; Wafa et al., 2024) |
| Compatibility | Whether the interface works on common smartphones and browsers | Tests on selected devices and browsers |
| Perceived usefulness and ease of use | Whether users find the system useful and easy to use | Evaluation questionnaire based on TAM (Davis, 1989; Kampa, 2023) and UTAUT (Venkatesh et al., 2003; Xue et al., 2024) |

Testing will use simulated records and test accounts. No real identity cards, phones or personal records will be used. Where photographs are needed, only neutral sample images or images of consenting volunteers will be used. After testing, participants from the three user groups will complete an evaluation questionnaire on a five-point Likert scale covering the five criteria and the TAM and UTAUT items, with a few open-ended questions. Brief follow-up discussions may be held with officers and administrators.
