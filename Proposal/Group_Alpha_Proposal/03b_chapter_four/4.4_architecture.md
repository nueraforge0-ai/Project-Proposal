### 4.4 Proposed Architecture

| **Layer** | **Technology** | **Responsibility** |
|----|----|----|
| Client | React progressive web application | Interfaces for users, officers and administrators; installable; works with limited connectivity |
| Server | Node.js with Express (REST interface) | Authentication, role checks, business rules, file handling, notifications |
| Database | MySQL | Users, items, reports, claims, releases, suggestions, logs |
| AI module | Server-side calls to an external AI service | Match suggestions, category suggestions and trend summaries, with personal data removed before sending |
| File storage | Server storage outside public folders | Item photographs, served only to authorised users |

The browser never talks to the AI service. All AI requests go through the server, which holds the key, removes personal data and records what was suggested.
