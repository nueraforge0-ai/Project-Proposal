### 4.5 Main Data Entities

| **Entity** | **Main fields** |
|----|----|
| User | Identifier, name, university number, contact, role, status |
| FoundItem | Identifier, category, description, photographs, date and time received, storage location, status, registered by |
| LostReport | Identifier, owner, description, place, time, optional photographs, status |
| Claim | Identifier, claimant, item, supporting details, officer decision, date |
| Release | Identifier, claim, officer, date and time released |
| MatchSuggestion | Identifier, lost report, found item, score, reviewed by, decision |
| Notification | Identifier, recipient, message, date, read status |
| AuditLog | Identifier, user, action, record, date and time |
