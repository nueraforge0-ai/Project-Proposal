### 4.6 Main Workflow: Claim and Release

1.  A finder hands an item to the Security Unit at the main gate.

2.  A Security Officer registers the item with photographs and a short description. The system suggests a category.

3.  The item appears in the register, with public details limited to category and general description.

4.  An owner searches the register or submits a lost report. The system compares the report with the register and ranks possible matches for the officer.

5.  The officer reviews a suggested match and, if it looks right, the owner is told that a possible match exists.

6.  The owner submits a claim with details that only the owner would know.

7.  The officer compares the details with the record, verifies the claim and releases the item. The release is recorded.

8.  If nobody claims the item by the end of the retention period, it is marked unclaimed for the Security Unit to decide what to do.
