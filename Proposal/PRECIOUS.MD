 1.6 Justification

This project is justified by the need to improve the management and recovery of lost and found property at Nkumba University by transitioning from a largely manual holding process to a more organised and accessible digital system. Students and staff will benefit from a convenient platform that allows them to access and search found-item records using their mobile devices or computers without necessarily visiting the Security Unit physically. The Security Unit will benefit from a centralised digital register for recording and managing found property, verifying ownership claims before releasing items, and maintaining records of all property releases, thereby improving accountability and transparency. University administrators will benefit from AI-assisted analytical reports showing trends in lost, found and unclaimed property, which can support informed decision-making, improve property management procedures and guide awareness campaigns within the university. Furthermore, the proposed system will build on existing university infrastructure, including the Security Unit (Nashonji, 2026) and Wi-Fi facilities in student hostels (Nalwanga, 2024), thereby complementing existing property-handling arrangements rather than replacing them.

In addition to addressing an institutional need, the project provides a practical application of key concepts and technologies in the field of Computer Science. The development of the proposed system will involve the application of several Computer Science concepts, including web application development, database design, user authentication, role-based access control (Rangappa, 2023), file management, information security, artificial intelligence integration, usability and data protection. These technologies and concepts will be integrated into a practical solution that can be tested and evaluated by actual users within the university environment.
I have made sure that our  justification agrees with the actual functions of our system:
- Students and staff can browse and search found items.
- Students create accounts to submit claims.
- Authorised Security personnel register found items.
- Security personnel verify ownership and record releases.
- Administrators access analytical summaries.
